# Crtyss 二维标志

从 `src/geometry-scene.js` 中的扭转环带模型提取，以首页初始姿态（Euler XYZ：1、0、-0.36 弧度）作正交投影，将投影三角面合并为外轮廓与内部留白，再简化为一个矢量路径。

- `crtyss-mark.svg`：深色、透明底的矢量标志。
- `crtyss-mark-white.svg`：白色、透明底的反白矢量标志。
- 两个同名 PNG：2048 × 2048 像素，透明底。
- `preview.html` / `preview.png`：黑白底展示和小尺寸预览；展示页文字不是标志图形的一部分。

轮廓使用单色表达，不包含模型的灯光、高光、阴影或贴图。内部留白为透明区域。网站中的头像、导航和 3D 模型尚未替换。
